# Нина Терентьевна рассказывает

Интервью с Ниной Терентьевной Авакян (Худобкиной), 1936 г. р., которое записал внук Дима 5 декабря 2015 года.
На странице можно слушать запись и одновременно читать расшифровку: звучащая фраза подсвечивается,
любую фразу можно нажать и услышать. Ещё на странице есть главы, жизнь по годам и семейные фотографии.

## Что в папке

| Файл | Что это |
| --- | --- |
| `index.html`, `style.css`, `app.js` | сама страница |
| `transcript.js` | расшифровка: каждая фраза со временем начала в записи |
| `content.js` | периоды жизни, главы, события и подписи к фотографиям; подписи можно править здесь |
| `audio/interview.mp3` | вся запись, 1 ч 23 мин, 35 МБ |
| `photos/` | фотографии из семейного альбома |
| `rasshifrovka.txt` | та же расшифровка обычным текстом, с обозначениями и списком непроверенных мест |
| `.nojekyll` | нужен GitHub Pages, не удалять |

## Как посмотреть на своём компьютере

Откройте `index.html` двойным щелчком. Всё работает без сервера; из интернета подгружаются только шрифты.

## Как выложить на GitHub Pages

Запись весит 35 МБ, а через сайт github.com можно загрузить файл не больше 25 МБ.
Поэтому загружать удобнее через [GitHub Desktop](https://desktop.github.com/) или командами `git`.

1. На github.com создайте новый репозиторий, например `GenInterviews`. Бесплатно Pages работают только для публичных репозиториев.
2. Загрузите в него **содержимое** этой папки (не саму папку). Командами это так:

   ```bash
   cd "путь/к/Сайт для GitHub"
   git init
   git add .
   git commit -m "Интервью с бабушкой, 2015"
   git branch -M main
   git remote add origin https://github.com/dimavak/GenInterviews.git
   git push -u origin main
   ```

3. В репозитории откройте **Settings → Pages**. В разделе *Build and deployment* выберите
   *Deploy from a branch*, ветку `main` и папку `/ (root)`, нажмите **Save**.
4. Через одну-две минуты сайт откроется по адресу `https://dimavak.github.io/GenInterviews/`.
   Эту ссылку можно отправить родным.

## Ссылка на определённый момент

Кнопка со звеньями цепи в проигрывателе копирует ссылку на текущее место записи.
Такую ссылку можно написать и вручную: `…/GenInterviews/#t=29:36` или `…/GenInterviews/#t=1776` (в секундах).

## Поисковики

В `index.html` стоит строка `<meta name="robots" content="noindex, nofollow">`: страница открывается всем,
у кого есть ссылка, но Google и Яндекс не будут показывать её в поиске. Если захотите, чтобы её можно было найти
поиском, удалите эту строку.

## Обозначения в расшифровке

Речь бабушки записана русскими буквами так, как она звучит: с белорусским говором и трасянкой, без исправлений.

- `[?]` — слово расслышано неуверенно;
- `[неразб.]` — место не удалось разобрать;
- `[= …]` — официальное название места, если она произносит его иначе;
- другие пояснения в квадратных скобках добавлены при расшифровке, в записи этих слов нет.
